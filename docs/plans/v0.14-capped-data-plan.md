## Solution — short synthetic traces per missing category

Three new generator scripts produce ≤ 500-token CoT traces in **Format 4** (no `<think>` opener):

### `scripts/generate_spelling.py`

Rule: concatenate all input words (drop spaces), then surround each character with `–` (EN DASH).

```
"hello world" → "–h–e–l–l–o–w–o–r–l–d–"
```

Prompt: 3 sample input→output pairs (Alice's Wonderland format) + 1 test input.  
CoT: ~150 tokens — identify concat+dash rule from examples, apply to test.

### `scripts/generate_equation_numeric_deduce.py`

Rule: each operator symbol (`*`, `$`, `&`, …) maps to one of `{add, abs_diff}`.

- `add` example: 42`$`39 = 81
- `abs_diff` example: 22`*`80 = 58 (abs_diff always uses a < b → result = b−a, unambiguous vs add)

CoT: ~300 tokens — try each candidate operation per symbol, declare winner, apply to test.

### `scripts/generate_equation_numeric_guess.py`

Same as deduce but operation pool includes **string concatenation** (the distinctive feature
of the "guess" category):

- `concat` example: 39`@`28 = 3928 ("39"+"28"=3928 — always 4-digit, unambiguous vs add/abs_diff)
- Always one concat symbol + one numeric symbol per puzzle.

CoT: ~350 tokens — try add / abs_diff / concat per symbol.

### Fix: `scripts/generate_equation_symbolic.py`

Removed spurious `"<think>"` opener from `build_cot()` — all 4 generators now produce
Format 4 consistently.

## v0.14 build pipeline

```zsh
# Step 1: generate all synthetic examples (no Docker needed, ~seconds)
python3 scripts/generate_spelling.py              --n 500 --seed 42 --out data/spelling_synthetic.jsonl
python3 scripts/generate_equation_numeric_deduce.py --n 500 --seed 42 --out data/eq_num_deduce_synthetic.jsonl
python3 scripts/generate_equation_numeric_guess.py  --n 500 --seed 42 --out data/eq_num_guess_synthetic.jsonl
python3 scripts/generate_equation_symbolic.py     --n 500 --seed 42 --out data/equation_symbolic_synthetic.jsonl

# Step 2: merge with v0.12 base
cat data/v0.12_train.jsonl \
    data/equation_symbolic_synthetic.jsonl \
    data/spelling_synthetic.jsonl \
    data/eq_num_deduce_synthetic.jsonl \
    data/eq_num_guess_synthetic.jsonl \
    > data/v0.14_merged.jsonl   # 27,500 rows

# Step 3: token-filter then cap/repeat (requires Docker for tokenizer)
# Wrapped by scripts/generate_v14_data.sh
docker run --rm --privileged -e NVIDIA_VISIBLE_DEVICES=all \
  -e HF_HUB_OFFLINE=1 -e TRANSFORMERS_OFFLINE=1 \
  --user $(id -u):$(id -g) \
  -v $(pwd):/workspace \
  -v $(pwd)/.cache/huggingface:/home/ubuntu/.cache/huggingface \
  -w /workspace nemotron-gb10:latest \
  python3 scripts/balance_dataset.py \
    --input  data/v0.14_merged.jsonl \
    --output data/v0.14_train.jsonl \
    --max-tokens 4096 \
    --max-per-category 1500 \
    --min-per-category 300 \
    --seed 42
```

### Risk flags

- **`bit_manipulation` at 10.7× repetition** — 28 unique examples repeated to 300; overfitting risk.
- **3 new categories are synthetic-only** — short CoT traces; model learns the rule but may not generalize to huikang-style long-form prompts at inference.
- **500 examples each for new cats** — at stratified batch_size=16 with 16 cats, each new-cat example is seen ~once over 500 steps (~0.625 epochs).
