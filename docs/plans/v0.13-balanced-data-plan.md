## Problem — v0.12 category imbalance

`data/v0.12_train.jsonl` has 25,500 examples but top 3 categories represent 40% of training:

| Category | Count | % of total |
|---|---|---|
| matching | 4,515 | 17.7% |
| concatenation | 2,851 | 11.2% |
| splitting | 2,850 | 11.2% |
| ... (5 more ≥ 2000) | — | — |
| equation_symbolic | **1** | 0.004% |

`equation_symbolic` is confirmed present in the test set but has 1 training example (from kishanvavdara). The StratifiedSFTTrainer provides batch-level mixing but does not equalize raw counts — it is zero-cost index reordering, not loss weighting.

**Root cause**: huikang augmenters generate unlimited examples for categories they support (matching, concatenation, splitting…). `equation_symbolic` has no huikang augmenter.

---

## Solution

### 1. Synthetic `equation_symbolic` generator

`equation_symbolic` puzzles are "Alice's Wonderland" rule-inference problems — infer a hidden transformation rule from 3 input→output examples, then apply it to a new input. Confirmed by inspecting the one existing training example (delete-'+'-characters rule, kishanvavdara source).

`scripts/generate_equation_symbolic.py` generates 4 rule types:
- `delete_op` — remove all occurrences of one operator character
- `replace_op` — replace one operator character with another
- `keep_op` — keep only the operator character, discard everything else
- `swap_ops` — swap two specific characters wherever they appear

Each puzzle has a templated CoT trace showing rule inference and application. Output: 500 unique examples with guaranteed-correct answers.

### 2. Dataset balancing

`scripts/balance_dataset.py` applies to any JSONL file:
- `--max-per-category N`: randomly downsample categories above N
- `--min-per-category M`: round-robin repeat categories below M

### 3. v0.13 build pipeline

```zsh
# Step 1: generate equation_symbolic (< 1 second, no GPU)
python3 scripts/generate_equation_symbolic.py \
    --n 500 --seed 42 \
    --out data/equation_symbolic_synthetic.jsonl

# Step 2: merge with existing v0.12 data
cat data/v0.12_train.jsonl data/equation_symbolic_synthetic.jsonl \
    > data/v0.13_merged.jsonl

# Step 3: balance
python3 scripts/balance_dataset.py \
    --input  data/v0.13_merged.jsonl \
    --output data/v0.13_train.jsonl \
    --max-per-category 1500 \
    --min-per-category 300 \
    --seed 42
```
